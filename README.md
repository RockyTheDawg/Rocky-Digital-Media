# Rocky Digital Media

Rocky Digital Media is a lightweight static site for GitHub Pages. The booking form includes common furry species and current worldwide convention choices through 2027.

## Sections

- Home
- Booking
- Travel
- Gallery
- About
- Contact

## Convention data

Convention choices are stored in `conventions.js` and were checked against FurryCons.com on August 8, 2026. Update that file when the calendar changes.

## Planned sections

Travel, Gallery, About, and Contact are intentionally empty until their final content is ready. The Gallery is reserved for a future Furtrack profile connection.
